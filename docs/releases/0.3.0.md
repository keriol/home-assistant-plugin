# Home Assistant Plugin 0.3.0 — Ignition

Home Assistant Plugin 0.3.0 is the HAP component of
**Ignition Phase 1 / IGNITION-001**, the first coordinated Butler network
baseline proven from Android into the shared Core world and Home Assistant.

## Why 0.3.0

HAP crossed two architectural boundaries before this release:

1. it became an independent Butler Core plugin rather than a Wilfred-owned
   integration;
2. that independent plugin is now validated inside the Android-reaching
   communication network.

The second boundary makes 0.3.0 the appropriate first network-valid release.

## Ignition role

```text
Interphone 0.1.0
      |
Bifröst 0.1.0
      |
Midgard 0.1.0
      |
Butler Core 0.3.0
      |
HAP 0.3.0
      |
Home Assistant
```

HAP remains Android-agnostic and non-conversational. It contributes typed
Home Assistant tools/capabilities and provider diagnostics to the Core world.

## Included

- consumer-neutral Butler Core dependency;
- canonical HAP plugin identity;
- Home Assistant endpoint/authentication setup semantics;
- secret-safe configuration diagnostics;
- readiness/availability probes;
- READ-only provider introspection;
- mapping validation diagnostics;
- authorized READ and ACTION tools;
- `home.state` and `home.control` capabilities;
- compatibility with READ -> ACTION -> READ -> VERIFY workflows.

## Boundary

HAP does not own:

- client/UI behavior;
- Bifröst transport;
- Midgard routing;
- conversational semantics;
- user confirmation policy;
- Home Assistant devices/dashboards/physical orchestration;
- private household mappings.

## Compatibility

The exact tested combination is recorded by the IGNITION-001 compatibility BOM.
This release candidate pins the exact Butler Core 0.3.0 release-candidate commit
used for combined proving. Final immutable release references are verified
before tags are published.
